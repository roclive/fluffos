# 功法 / 门派 / 武学常识

> 同样：分类与机制是标准侠客行体系，**具体招式名、伤害、门派归属务必以服务器源码或游戏内
> `skills` / `查看武功` 输出为准**。`data/skills.json` 应由 `extract_mudlib.py` 从源码生成。

## 1. 功法分类（技能大类）

侠客行武功按"技能类型"组织，agent 决策时应区分：

| 类别 | 作用 | 战斗中的角色 |
|---|---|---|
| 内功 (internal) | 提升内力上限、运功疗伤、内伤恢复 | 资源底座，先练高 |
| 拳脚 / 基本内功外的徒手 | 徒手攻击 | 无兵器时的攻击手段 |
| 剑法 / 刀法 / 棍法 / 鞭法… (weapon) | 持对应兵器时的攻击招式 | 主输出，需配兵器 |
| 招架 (parry) | 格挡 | 减伤 |
| 闪躲 / 轻功 (dodge / qinggong) | 闪避、赶路移动 | 生存与机动 |
| 特殊技能 / 心法 | 门派特有增益或绝技 | 进阶 |

**机制要点：**
- 学武功消耗 `潜能(potential)`，并受 `悟性` 与 `武学常识` 上限限制。
- 兵器类武功需要"装备对应兵器"才能发挥；徒手时自动退回拳脚。
- 内功等级影响其他武功的有效发挥与内力池。

## 2. 门派（sect）

每个门派有独立的入门、师傅 NPC、专属武功树、声望/正邪倾向。少林作为示例：

- **少林派**：佛门，正派。代表武功方向：罗汉拳、韦陀掌、易筋经（内功）、少林长拳等。
  入门通常需到少林寺找相应 NPC 拜师。
- 其他常见门派：武当、峨眉、丐帮、华山、全真教、明教等（以源码 `/d/` 与门派目录为准）。

> 具体门派列表、入门条件、武功清单：从 mudlib 的门派目录（如 `/kungfu/`、`/d/shaolin/`）提取，
> 写入 `data/skills.json`，并标注 sect 字段。

## 3. 武学常识（combat literacy）

- 通过"读书识字 / 看书"提升 `武学常识`，它是各项武功能学到多高的总闸门。
- agent 长期策略：早期适当投入提升常识，否则高级武功练不上去。

## 4. agent 可直接用的决策提示

- 没兵器又要打架 → 用拳脚类；有兵器 → 切到对应兵器武功。
- 内力低 → 先打坐补内力再发招。
- 想变强的最短路径 = 内功 + 主攻武功 + 招架/轻功 三条线均衡，受潜能与常识约束。
